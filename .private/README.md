# splanard.github.io

## Installation

- Installer (Ruby 3.4)[https://www.ruby-lang.org/en/documentation/installation/] (≥ 2.7.0 | < 4.0)  
  Pour vérifier, exécuter `ruby -v` sur un terminal

- Exécuter `bundle install` à la racine du projet

## Utilisation

- Exécuter `bundle exec jekyll serve` pour lancer le site

- Naviguer vers http://localhost:4000/
